# Latihan GUI Java Swing - Aplikasi Biodata Mahasiswa

**NIM  :** F1D02510008
**Nama :** HARI FITRATULLAH

Aplikasi sederhana untuk mengisi biodata mahasiswa.

## 5 Komponen Utama GUI yang Digunakan

| No | Kategori | Kelas / Antarmuka | Fungsi dalam aplikasi |
|----|----------|-------------------|-----------------------|
| 1 | Kontainer Tingkat Atas | `JFrame` | Jendela utama aplikasi |
| 2 | Kontainer Menengah | `JPanel`, `JScrollPane` | Mengelompokkan komponen (judul, form, tombol) dan area gulir hasil |
| 3 | Komponen Atom | `JLabel`, `JTextField`, `JComboBox`, `JButton`, `JTextArea` | Elemen input dan output |
| 4 | Kelas Tata Letak | `BorderLayout`, `GridLayout`, `FlowLayout` | Mengatur posisi komponen |
| 5 | Pendengar Peristiwa | `ActionListener` (antarmuka), `MouseAdapter` & `WindowAdapter` (adaptor) | Menangani klik tombol, hover mouse, dan penutupan jendela |
